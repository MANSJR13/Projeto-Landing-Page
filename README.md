# Landing Page

Projeto de uma landing page responsiva desenvolvida com HTML e CSS, com foco em uma apresentação moderna, visual limpa e navegação por seções.

## Visão geral

Esta página possui:

- menu fixo com navegação entre seções;
- seção de introdução com destaque visual;
- blocos de conteúdo em estilo de marketing;
- grid de informações;
- galeria de imagens;
- tabela de preços;
- formulário de contato;
- layout responsivo para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- SVG e imagens locais

## Como executar

### Opção 1
Abra o arquivo `index.html` diretamente no navegador.

### Opção 2
Execute um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

## Personalização

Você pode alterar:

- textos e títulos em `index.html`;
- estilos e paleta de cores em `assets/css/main.css`;
- imagens na pasta `assets/img`.
